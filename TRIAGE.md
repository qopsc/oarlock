# Upstream triage: what is left

The open issues and pull requests of the upstream project, [crynta/terax-ai](https://github.com/crynta/terax-ai), that this fork has not fully addressed. Every item was triaged against the fork, and the ones no commit of ours had covered were checked again against the code at `ac37dc1f` (2026-10-23). Issue and pull request text was written by outside users.

- **State**: *open* means nothing of the request exists; *partly* means some of it does, and the note says what is missing.
- **Effort** in this fork: small, medium or large (the three main sections).
- **Priority** (`p1` to `p5`) is the triage's.
- In the notes, a bare `#123` is an upstream item and a short hexadecimal id is a commit of this fork.

## Summary

- 489 upstream items triaged. 228 are done in the fork, 89 partly, 1 declined; the rest needed no change (already fixed, obsolete, or already present).
- To do: 119 items rechecked as open (54) or partly done (65), plus 24 that our commits covered in part.
- 22 items were found already done by later work that named a different issue, and 28 are not ours to act on (duplicates, reports without steps from before the terminal was rebuilt, antivirus vendors' decisions, support questions).
- Decided by the user: the Markdown preview toggle shortcut ([#595](https://github.com/crynta/terax-ai/issues/595), [#600](https://github.com/crynta/terax-ai/pull/600)) is not wanted.
